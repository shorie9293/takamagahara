# UX監査：開発神事の摩擦分析（天宇受賣命）

- **奏上日**: 皐月四日（2026-05-04）
- **奏上者**: 天宇受賣命（アメノウズメ）— UXの神
- **発端**: 創造主様「神勅も増えてきて混乱する」
- **元神書**: `shinsho/ux-audit-20260504.md`

## 核心診断

アマテラスが独りでコードを書くのは「合理的なショートカット」。
**掟破りの原因は怠慢ではなく、神事のUX設計の欠陥**。

## 3大ペインポイント

### ① 四神召喚のオーバーヘッド（致命）

- 並列召喚で数十秒〜数分の待ち → typo1行修正に見合わない
- トークン数数千〜数万が溶ける → 有限のAPI予算を圧迫
- 「創造主様を待たせている」心理負荷
- **比喩：コンビニに行くのに車を出す**

### ② 神勅の認知負荷超過（増幅因子）

- 11神勅がフラットに並ぶ → 7±2の短期記憶限界超過
- 第四・第九・第十一が**実質同じ内容を3度言い換え**
- 「してはいけない」の洪水 → 禁止より誘導で動く

### ③ タスク粒度のミスマッチ（構造問題）

- 神事は「神想→神議→試練→具現化」のフルサイクル想定
- 1行修正・typo修正・文言変更のユースケース未対応

## 改善提案（要旨）

- 「軽微修正モード」新設：眷属神なしで即実行可能な例外パス
- 神勅の統合：重複3神勅を1つに
- 掟を「してはいけない」から「こうする」の誘導型に

## 現在の反映状況

- 神勅統合 → AGENTS.md v1.4で一部改善
- 軽微修正モード → 未実装
- 誘導型記述 → 部分的に反映
