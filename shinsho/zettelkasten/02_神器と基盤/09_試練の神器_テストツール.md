## テストツール一覧

| 神器 | 用途 |
|------|------|
| `flutter_test` | Widget/Unitテスト（SDK組込） |
| `integration_test` | 統合テスト（実機/エミュレータ） |
| `mocktail`（^1.0.4） | モック生成。`when(() => mock.method()).thenAnswer(...)` |
| `build_runner` + `injectable_generator` | DIコード自動生成 |

---

## 実行コマンド

```bash
flutter test                          # 全試練
flutter test --coverage               # 網羅率
flutter analyze                       # 静的解析
genhtml coverage/lcov.info -o coverage/html  # 網羅率レポート（要lcov）
```

---

## テストピラミッド

| 種類 | 対象 | 速度 | 比率 |
|------|------|------|------|
| Unit | ViewModel/UseCase/Model | ms | 70% |
| Widget | 個別Widget | 数百ms | 20% |
| Integration | 画面遷移・E2E | 秒 | 10% |
