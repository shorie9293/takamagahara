## 神機（AI）連携の全体像

高天原の現世は、LLM（大規模言語モデル）APIを通じて神機の力を借り受ける。
直接APIを叩くのではなく、Supabase Edge Functionsを経由した安全な呼び出しが基本。

---

## 連携アーキテクチャ

```
現世（Flutterアプリ）
    │
    │ HTTPS + JWT
    ▼
Supabase Edge Functions（Deno）
    │
    │ API Key（サーバー側で保持・クライアントには渡さない）
    ▼
LLM API（Anthropic Claude / OpenAI / DeepSeek 等）
```

---

## 対応LLMプロバイダ

| プロバイダ | モデル例 | 用途 |
|-----------|---------|------|
| Anthropic | Claude | 守護神AI講評（Kozuchi）・文章生成 |
| OpenAI | GPT-4o | 汎用AI機能 |
| DeepSeek | DeepSeek-V3 | コスト重視のAI機能 |
| Google | Gemini | 魔導書解析（rpg-task v2） |

---

## 安全策

1. **API Keyはクライアントに渡さない** — Edge Functionsでサーバー側管理
2. **レート制限** — Edge Functions側で実装
3. **Feature Flag制御** — 未完成なAI機能はFeature Flagで制御（rpg-task v2方式）
4. **オフラインフォールバック** — AIが使えない時はローカルルールベースで動作
