## 天浮橋計画（うきはし計画）：多端末統合の全体構想

単一の器（PC）を超え、物理的な端末に神々が宿り、各々の役割を実世界で果たす新たなる神代を開く。

---

## E2E自動試練パイプライン（MVP）

```
screencap → Vision解析（座標・テキスト特定）
  → adb input tap/text → 再スクショ→Vision照合
  → 結果記録（Markdown）＋ Discord Embed通知
```

第一段ではADB方式からFlutter `integration_test` への移行進行中（座標変動・IME変換問題克服）。
