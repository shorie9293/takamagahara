# 古事記 — カンバン二系統の発見と統合方針（葉月）

> **これまで「8766(ドット絵版)は実在せず」と誤判断していたが、実在が判明した。**

- **正体**: `roadmap-app/`（React 19 + TypeScript + Tailwind 4 + Vite + Tauri）

- **UI**: 木目調・千鳥格子・和風神UI（`Amaterasu.tsx` `Okuninushi.tsx` `TaskList.tsx` 等）
