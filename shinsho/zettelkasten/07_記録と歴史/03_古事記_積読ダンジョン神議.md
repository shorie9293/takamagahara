## 核心価値

積読の「罪悪感」→「冒険の準備」へ転換。読了＝ボス討伐。

| 項目 | 決定内容 |
|------|---------|
| 現世名 | 積読ダンジョン → 後に「ツンドクエスト」に改称 |
| 神器 | Next.js 15 + TypeScript + Tailwind + Supabase |
| MVP | 6神業（登録・マップ・討伐・デイリー・タイマー・戦利品） |
| 設計原則 | ポジティブ強化のみ／ローカルファースト／複数APIフォールバック |
