# rpg-task Title System (称号システム)

**status**: stub — 詳細神想は未策定。クロスサービス報酬設計から参照される受け皿ノート。

## Summary

rpg-task が付与する称号（Title）の体系。tsundoku-quest 等の他現世からの報酬イベントを受け、
読書実績・継続・XP・ページ数のマイルストーンに応じて称号を授与する。

## 称号カテゴリ（クロスサービス報酬より）

| 契機 | 称号例 |
|------|--------|
| book_completed (1/5/10/50) | 読書家の卵 / 書庫の冒険者 / 知の探究者 / 千巻の賢者 |
| reading_streak (7/30/100) | 読書の継続者 / 日々の読書人 / 不滅の読書家 |
| xp_milestone (1000/10000) | 知識の探求者 / 知の航海者 |
| pages_milestone (1000/10000) | ページを征く者 / 万頁の読破者 |
