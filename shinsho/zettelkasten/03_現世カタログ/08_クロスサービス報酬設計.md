## Summary

tsundoku-quest reading progress triggers rpg-task rewards (titles, coins, EXP).
Transport: JSONL file at `/data/local/tmp/takamagahara_shared/tsundoku_reward_events.jsonl`.
Identity: Supabase `auth.users(id)`.

## Event Types

7 event types: `book_completed`, `reading_streak`, `level_up`, `xp_milestone`, `trophy_written`, `daily_mission_complete`, `pages_milestone`.

## Reward Mapping

| tsundoku trigger | rpg-task reward |
|-----------------|-----------------|
| book_completed (1/5/10/50) | Titles: 読書家の卵/書庫の冒険者/知の探究者/千巻の賢者 |
| reading_streak (7/30/100) | Titles: 読書の継続者/日々の読書人/不滅の読書家 |
| xp_milestone (1000/10000) | Titles: 知識の探求者/知の航海者 |
| pages_milestone (1000/10000) | Titles: ページを征く者/万頁の読破者 |
| all events | Coins + EXP bonuses |

## Identity

Phase 1: Manual link code (first 8 chars of tsundoku user_id).
Phase 2: Supabase Auth on rpg-task → automatic match.
