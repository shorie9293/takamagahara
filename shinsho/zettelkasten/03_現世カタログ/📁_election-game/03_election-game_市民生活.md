## 市民生活パラメータ

一市民の目線で「自分の生活」に影響する6パラメータ。各0〜100で変動。職業により初期値と重要度が変わる。

---

## 6パラメータ

| パラメータ | 影響する公約 |
|-----------|------------|
| 💰 生活費 | 増税/減税、公共料金 |
| 🏥 医療 | 医療予算、保険制度 |
| 🏫 教育 | 教育予算 |
| 🏭 仕事 | 産業政策、最低賃金 |
| 🌳 環境 | 環境規制、公園整備 |
| 🚔 治安 | 警察予算、防犯政策 |

---

## 職業による変化

| 職業 | 初期重要度 |
|------|----------|
| 農家 | 環境70/生活費40、関心事「農業政策」「気候変動」 |
| 医者 | 医療優先、関心事「医療予算」 |
| 教師 | 教育優先、関心事「教育政策」 |
| 商人 | 経済/生活費優先、関心事「減税」 |
| 職人 | 治安/仕事優先、関心事「産業振興」 |

8種＋ランダムの職業から選択。各職業で3つまで関心事を設定。
