## 網羅率追跡の自動化

| 手段 | 内容 |
|------|------|
| `flutter test --coverage` | lcov形式の網羅率レポート |
| `genhtml coverage/lcov.info` | HTMLレポート生成 |
| CIに組み込み | Pull Requestごとに網羅率低下を検知 |
| 目標: 網羅率が下がったPRはマージ不可 |
