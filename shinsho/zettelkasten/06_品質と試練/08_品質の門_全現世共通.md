## 開闢（デプロイ）前の通過必須門
全Flutter現世が「現世への降臨」前に通過すべき8つの品質ゲート。一つでも落ちれば開闢不可。
---
## 8つの門

| # | 門 | 合格条件 | 自動/手動 |
|---|----|---------|----------|
| 1 | 静的解析 | dart analyze warning/error 0 | 🤖 自動 |
| 2 | 全試練通過 | flutter test 全件PASS | 🤖 自動 |
| 3 | Semantics検証 | interactive数 ≥ onPressed数 | 🤖 自動 |
| 4 | AppKeys一意性 | 重複Key 0 | 🤖 自動 |
| 5 | ErrorBoundary | 全画面ルートラップ確認 | 🤖 自動 |
| 6 | ファイルサイズ | 全.dart ≤ 200行 | 🤖 自動 |
| 7 | 統合試練 | E2E全シナリオPASS | 🤖/👤 半自動 |
| 8 | 目視確認 | 実機UI/UX操作確認 | 👤 手動 |
---
## 一括実行

```bash
bash scripts/run-quality-gates.sh
```
---
## 開闢不可の判定例

| 状況 | 理由 |
|------|------|
| 試練1件FAIL | Gate 2落ち |
| Semantics不足 | Gate 3落ち |
| AppKeys重複 | Gate 4落ち |
| guild_screen 923行 | Gate 6落ち（例外なし。分割が唯一の解決策） |
---
## 奏上形式

```
✅ 品質の門 全8門通過
  Gate 1: dart analyze — clean
  Gate 2: flutter test — 215/215 PASS
  Gate 3: Semantics — interactive ≥ onPressed
  Gate 4: AppKeys — 重複0
  Gate 5: ErrorBoundary — 4/4画面ラップ
  Gate 6: ファイルサイズ — 全 ≤ 200行
  Gate 7: E2E — 6/6 PASS
  Gate 8: 目視 — 確認済み
→ 開闢許可
```
