## 「天の遊び（アメノアソビ）」ブランド体系

**キャッチコピー**: 「人生を、神遊びに。」

---

## 各アプリのブランド位置づけ

| 現世 | タグライン |
|------|-----------|
| RPG Task | 「冥府の帳簿 — 日々の務めを冒険譚に」 |
| Tsundoku Quest | 「積読の迷宮 — 読書を探索に」 |
| Election Game | 「八百万の審判 — 投票を神議に」 |
| Lifelog News | 「日々は神話 — 日常を叙事詩に」 |
| Book Review | 「書評の神楽 — 読後を舞に」 |
| PTA Reform | 「地域の社 — 共同体を再建せよ」 |

---

## ビジュアル設計

| 要素 | 値 |
|------|-----|
| 基調色 | 金（#D4A038）— 高天原の光 |
| 副色 | 深紫（#1A1040）— 神話の深淵 |
| アクセント | 朱（#E85050）— 天宇受賣命の情熱 |
| 補助 | 白（#F5F0E8）— 和紙の質感 |
| UIトンマナ | 和モダン×ピクセルアート |

**ロゴ案**: 八咫鏡をモチーフにした円形＋中央に「天」の古字

---

## クロス連携UX「神魂（かみたま）」

全アプリ共通アバター。各現世の達成が「神力」として蓄積、装備品で表現。
