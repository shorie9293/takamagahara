# 13_神事の手引_具現化四段階_詳細

**カテゴリ**: 01_大願と掟 | **ソース**: AGENTS.md §3.3 | **親ノート**: [[13_神事の手引_具現化四段階.md]]

---

## 各段階の詳細

### 第一段：神議（プランニング）
1. 四神を召喚し、多角的な分析を行う
2. `writing-plans` を用いて計画書を `.hermes/plans/` に起草
3. 計画書には「何を作るか」「どう作るか」「どう検めるか」を明記

### 第二段：委任（実行）
**規模に応じた委任方式の選択：**

| 規模 | 目安 | 方式 |
|------|------|------|
| **小神事** | 1ファイル・20行以下・ロジック変更なし | `patch`（イシコリドメが直接） |
| **中量** | 新規Widget/モデル・50〜200行 | `delegate_task(role='leaf')` |
| **重量** | 機能全体・複数ファイル・1000行超 | `delegate_task(role='orchestrator')` |

重量タスクでは orchestrator 内で四神分析を行い、leaf眷属神に層ごとに分割委任する。

### 第三段：試練（検証）
```bash
# 1. 全試練の実行
flutter test --no-pub

# 2. 静的解析
dart analyze lib/

# 3. 網羅率確認
flutter test --coverage
```

🔴 RED → 🟢 GREEN → 🔵 REFACTOR の循環を厳守。

### 第四段：奏上（報告）
1. 成果を簡潔に奏上
2. 意思決定事項を `shinsho/kojiki.md` に追記
3. 現世の個別道標（`utsushiyo/<現世>/docs/roadmap.md`）を更新
