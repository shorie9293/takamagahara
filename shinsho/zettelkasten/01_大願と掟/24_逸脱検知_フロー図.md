# 逸脱検知フロー図

**親ノート**: [[14_神事の手引_逸脱検知.md]]

```
自律具現化中
    │
    ├─ 進捗あり → 継続
    │
    ├─ 逸脱兆候を検知
    │       │
    │       ▼
    │   clarify で創造主様に伺い
    │       │
    │       ├─ 指示あり → 指示に従い再開
    │       └─ 応答なし → 自律判断で中断・次タスクへ
    │
    └─ 30分経過（cron実行時）→ 中断・次タスクへ
```
