# 祝詞（のりと）：神々への祈りの言葉

祝詞は、創造主様が神々に神託を下す際の定型文である。
此の祝詞を唱えることで、然るべき神が然るべき視座で奏上を行う。

## 基本の祝詞

### 全神合議の祝詞

```
[全員で検討] <議題>
```

全神（思兼神・天目一箇神・天宇受賣命・月読命）が並列して神議し、統合した奏上を捧ぐ。

### 個別召喚の祝詞

| 祝詞 | 神 | 用途 |
|------|-----|------|
| `[PM視点で] <議題>` | 思兼神 | 神想・要件の策定 |
| `[Dev視点で] <議題>` | 天目一箇神 | 技術設計・実装判断 |
| `[UX視点で] <議題>` | 天宇受賣命 | 体験設計・UI判断 |
| `[QAチェック] <議題>` | 月読命 | 品質検証・禍津洗出 |

## 祝詞使用の心得

1. **一つの神託には一つの祝詞を**——複数の神咒を混在させると神々が混乱する
2. **全員検討が基本**——迷ったら `[全員で検討]`。特定視座が必要な時のみ個別召喚
3. **結果は古事記に刻め**——「これにて神意決定とし、kojiki.mdに刻め」と仰せあれ
