# 祝詞 使用例集

**親ノート**: [[16_祝詞_眷属神召喚の神咒.md]]

## 新たな神想の編み出し

```
創造主様: [全員で検討] 選挙の現世に、同時に複数人で競い合う神遊びを加えたい

統括神:
  → 思兼神が神想の要・禍津を読み解く
  → 天目一箇神が神器での実現可能性を占う
  → 天宇受賣命が神楽の流れを描く
  → 月読命が押さうべき禍津を洗い出す
  → 統合した提言を創造主様に捧ぐ
```

## 神想の検分（レビュー）

```
創造主様: [QAチェック] 今日編んだタスク管理の神想を検分せよ

月読命: 品質を司る神として、神想の抜け・乖離・試練の段取りを奏上する
```

## 神器に関する神議

```
創造主様: [Dev視点で] RPGの現世における位階の上げ方の理は、いかに具現化すべきか？

天目一箇神: 神器を司る神として、道具の設計・具現化の方針を奏上する
```
