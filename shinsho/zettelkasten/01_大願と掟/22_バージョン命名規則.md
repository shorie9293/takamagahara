# バージョン命名規則とチェックリスト

**親ノート**: [[15_開闢の手順_バージョン上げ.md]]

## バージョン命名規則

```
version: <メジャー>.<マイナー>.<パッチ>+<ビルド番号>
```

- **メジャー**: 大規模変更・後方互換性の破壊
- **マイナー**: 機能追加・後方互換性あり
- **パッチ**: 禍津修正・軽微な改善
- **ビルド番号**: 単調増加。Play StoreのversionCode

## チェックリスト（具現化前）

具現化着手前に以下を確認せよ：

- [ ] `pubspec.yaml` の `version` が更新されているか
- [ ] ビルド番号が前回より1以上大きいか
- [ ] `flutter test --no-pub` が全通過するか
- [ ] `dart analyze lib/` に警告がないか
